# Delivery Step (خطوة التوصيل): brand guide

Approved by the owner on 31 Oct 2026: the designer's original logo, with the Arabic name completed
(«التوصيل» → «خطوة التوصيل»). The icon and the English "DELIVERY STEP" are the designer's own, unchanged.

## Logo files (`brand/logo/`)
| File | Use |
|---|---|
| `logo-main` | Wide logo on white or light backgrounds: website, invoices, van side, signs |
| `logo-main-white` | Same, all white, on the brand pink or dark backgrounds: van, shirts, bags |
| `logo-stacked` / `-white` | Square places: delivery box, WhatsApp / Instagram posts, stickers |
| `icon` / `icon-white` | The D-arrow alone: app icon, profile pictures, small spaces |
| `designer-original-2025.pdf` | The designer's file, kept for reference (Arabic name incomplete) |

Formats: **.pdf / .svg** = vector, for printers and sign makers (any size, the Arabic is already outlines, no font
needed). **.png** = 2000 px wide with a see-through background, for screens, WhatsApp, Word.

## Fonts
- Arabic name in the logo: Noto Kufi Arabic (Regular) — already turned into outlines in the logo files.
- App and website text: Tajawal (already used everywhere).
- English: the logo's own letters; for other English text use Tajawal or Readex Pro.

## Rules
- Keep empty space around the logo, at least the width of the arrow tip.
- Smallest size: the full logo 3 cm wide in print / 120 px on screens; smaller than that, use the icon alone.
- Never stretch, rotate, recolour, add shadows, or place it on a busy photo.
- One-colour jobs (embroidery, rubber stamp, single-colour stickers): use `-white` on pink or ask for a flat
  one-colour version of the icon (a flat version was drafted on 31 Oct, scratchpad brand1/board2).
